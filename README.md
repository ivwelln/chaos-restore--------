# chaos-restore

Восстановление хаотического сигнала, искажённого после прохождения через среду, с помощью нейронной сети.

Сигнал x(t) системы Лоренца проходит через фильтр нижних частот с «неизвестными» параметрами, к нему добавляется белый шум. Одномерный свёрточный автоэнкодер восстанавливает по искажённой записи исходный сигнал. Результат сравнивается со сглаживанием и обратной фильтрацией, качество оценивается ошибкой (NRMSE), фазовым портретом и старшим показателем Ляпунова (`nolds.lyap_r`).

## Запуск

Нужен Python 3.12 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python run.py generate             # шаг 1: эталонный сигнал
python run.py distort              # шаг 2: искажение сигнала
python run.py main                 # шаги 5–6: простые методы и автоэнкодер
python run.py exp snr              # шаг 7: влияние уровня шума
python run.py exp window           # шаг 8: влияние длины окна (64–1024)
python run.py exp arch --seeds 3   # шаг 9: автоэнкодер, U-Net, WaveNet
python run.py exp filters          # шаг 10: другие фильтры
```

Общие ключи: `--quick` – короткий прогон для проверки работоспособности, `--no-lyap` – без расчёта показателя Ляпунова, `--name ИМЯ` – подпапка в `results/`, `--set ключ=значение` – изменить параметр конфига (например, `--set channel.snr_db=20`), `--config путь` – другой конфиг.

Номера шагов: 1 – эталонный сигнал, 2 – искажающая среда, 3 – окна и подготовка данных, 4 – метрики, 5 – простые методы, 6 – автоэнкодер, 7–10 – дополнительные исследования. Все эксперименты на CPU занимают около полутора часов.

## Как устроен прогон

1. Система Лоренца (σ = 10, ρ = 28, β = 8/3) интегрируется с шагом dt = 0.01 на 4000 единиц времени – 400 000 отсчётов; сигналом служит x(t).
2. Сигнал проходит через ФНЧ Баттерворта 4-го порядка с частотой среза fc = 3, затем добавляется шум с SNR = 10 дБ.
3. Ряд делится по времени: 72 % – обучение, 8 % – валидация, 20 % – тест. Простые методы подбираются на обучающей части, сеть обучается на окнах длины L = 256.
4. Каждый метод восстанавливает тестовую часть целиком, и метрики считаются по ней. По L отсчётов с каждого края теста отбрасываются – одинаково для всех методов.

## Ключевые функции

- `lorenz.simulate` – интегрирует систему (`scipy.integrate.odeint`, rtol = 1e-10) и отбрасывает переходный процесс. `lorenz.get_signal` кэширует траекторию в `data/`, чтобы все эксперименты работали с одним и тем же сигналом.
- `channel.apply_channel` – модель среды: каузальный ФНЧ (`butter` / `bessel` / `cheby1` + `lfilter`) и белый гауссов шум. SNR задаётся относительно мощности уже отфильтрованного сигнала.
- `windows.frame_signal` и `windows.overlap_add` – нарезка ряда на перекрывающиеся окна и обратная сборка: окна взвешиваются окном Ханна и делятся на сумму весов, поэтому без сети сборка точна до машинной точности.
- `datasets.make_splits` и `datasets.prepare` – разбиение строго по времени, без перемешивания (иначе перекрывающиеся окна попали бы и в обучение, и в тест), и z-нормировка по статистикам только обучающей части.
- `baselines.fit_baselines` – подбирает на обучающей части параметры простых методов: скользящего среднего, фильтра Савицкого–Голея, ФНЧ нулевой фазы и обратных фильтров (прямой, Винер со скалярной λ, Винер по спектральным плотностям). Задержку, которую вносит канал, каждый метод компенсирует сдвигом по максимуму взаимной корреляции (`estimate_shift`).
- `baselines.BlindInverse` – обратный фильтр, который не знает параметров канала: подгоняет к спектру искажённого сигнала модель «экспоненциально спадающий спектр × АЧХ Баттерворта + уровень шума» и по ней оценивает частоту среза и порядок фильтра.
- `models.ConvAutoencoder` – основная сеть: кодер из трёх свёрток (32 → 64 → 128 каналов, ядро 7, длина L → L/4) и зеркальный декодер на транспонированных свёртках. `UNet1D` добавляет skip-связи, `WaveNet1D` – стек residual-блоков с дилатациями 1…128 без понижения разрешения. Число параметров у трёх сетей сопоставимо (145–177 тыс.).
- `train.train_model` – Adam, MSE на нормированных окнах, ранняя остановка по валидации; возвращается модель с лучшей эпохи. `train.restore_signal` прогоняет через сеть непрерывный участок сигнала (окна с шагом L/2) и собирает его через `overlap_add`.
- `metrics.lyapunov` – старший показатель Ляпунова через `nolds.lyap_r`. Ряд прореживается в 10 раз, параметры один раз подобраны на чистом сигнале командой `python run.py calibrate-lyap` и дальше не меняются. `metrics.first_minimum_lag` выбирает задержку для фазового портрета по первому минимуму взаимной информации.
- `pipeline.build_case`, `run_baselines`, `run_network` – шаги одного прогона; эксперименты в `experiments/` вызывают их с разными параметрами.

## Результаты

Папка `results/full` получена командами `main` и `exp` из раздела «Запуск» с ключом `--name full`:

- `metrics_main.csv`, `figures/` – основной прогон: все методы на тестовой части и рисунки к ним;
- `e_snr/`, `e_window/`, `e_arch/`, `e_filters/` – таблицы и рисунки шагов 7–10;
- `checkpoints/` – веса обученных сетей, `config.yaml` – параметры прогона, `log_*.txt` – вывод программы.

В `results/base/figures` – рисунки шага 1 (команда `generate`).

| Метод (тестовая часть) | NRMSE | λ₁ |
|---|---|---|
| эталон | 0 | 0.884 (табличное 0.906) |
| искажённый сигнал | 1.422 | 0.614 |
| лучший простой метод – Винер по спектральным плотностям | 0.094 | 0.765 |
| автоэнкодер | 0.077 | 0.811 |

Сравнение архитектур (`e_arch/metrics_arch_summary.csv`, среднее по трём seed): автоэнкодер – NRMSE 0.077, U-Net – 0.075, WaveNet – 0.033.
